# The hackathon — the governing text

A transcription of the Nebius x NVIDIA Global AI Hackathon pages. It changes only when the source changes. Where this page and
Devpost disagree, Devpost is right and this page gets fixed.

Sources: <https://nebiusglobalaihackathon.devpost.com/> and
<https://nebiusglobalaihackathon.devpost.com/rules>.

## Dates

| what | when |
|---|---|
| Submission deadline | 2026-10-30, 10:00 PDT (17:00 UTC) |
| Our own deadline | 2026-10-29 |

## What a submission must have

- A working application that runs on Nebius Token Factory or Nebius AI Cloud
  and uses at least one NVIDIA open source model
- A public code repository with an open source license
- A README with setup instructions
- A working demo link or test build
- A text description of the features
- A video of three minutes or less showing it working
- Feedback on the Nebius and NVIDIA tools used

Work must be new, or significantly updated after the submission period opened.

## Tracks

| track | what it asks for |
|---|---|
| **Coding and Agentic Engineering** (ours, see D-02) | coding agents and developer tools: agents that write, run and test code in Token Factory Sandboxes |
| Best Apps and Agents | practical applications or autonomous systems using Nemotron models |
| Personal AI | an always-on, private assistant that keeps your data under your control |
| Physical AI | embodied agents; the video must show the hardware operating for at least one minute |

## Prizes

| prize | amount |
|---|---|
| Grand / 2nd / 3rd | $20,000 / $10,000 / $6,000 |
| Track winner, each track | NVIDIA Jetson Orin Nano |
| Best Use of Tavily | $3,000 |
| City Winner | $500 x 20 |
| Most Valuable Feedback | $100 x 10 |

A project can win one overall **or** one track award, plus at most one bonus
award.

## Judging

Stage one is pass or fail: does the project genuinely attempt the track's goal.
Stage two is four equally weighted criteria:

1. **Technological implementation** — effective use of Nebius and NVIDIA models
2. **Design** — a complete, coherent product experience
3. **Potential impact** — solves a real problem for a real audience
4. **Quality of the idea** — creative and non-obvious

## Eligibility

18 or over; not an employee or family member of the organisers or judges; not
resident in a sanctioned country. Teams are allowed.

## What the last Nebius judges rewarded

From the Serverless AI Builders Challenge write-up
(<https://nebius.com/blog/posts/serverless-ai-builders-challenge-winners>),
every one of the top three had a **measured, non-obvious finding**: two
cross-family LLM judges agreeing at near-random (Cohen's kappa 0.11);
self-hosting only winning on cost at high utilisation; majority voting
surviving a saboteur agent at 100% accuracy. The judges also named exact cost
accounting, reproducibility and real-world utility.

That is a different competition with its own judges, so it is a hint and not a
rule.
